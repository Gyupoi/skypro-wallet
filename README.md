# Skypro.Wallet

Веб-приложение для учета и анализа личных расходов.

## Возможности

- регистрация и авторизация пользователя;
- просмотр списка расходов;
- добавление нового расхода;
- выбор категории расхода;
- удаление расхода;
- фильтрация расходов по выбранному периоду;
- анализ расходов по категориям;
- адаптивная вёрстка.

## Технологии

- React
- React Router
- Vite
- JavaScript
- CSS
- REST API
